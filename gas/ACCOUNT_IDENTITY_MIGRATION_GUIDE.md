# دليل تصحيح هويات حسابات أَثَر

## الحالة
هذا الإجراء أداة صيانة يدوية لمرة واحدة. وجود الملف في GitHub لا يغيّر Google Sheets أو مشروع Apps Script تلقائياً.

## الترتيب المعتمد
- مريم محمد سيف سالم النيادي: `principal` / `school_admin`
- صالحه مبارك محمد عبدالله البلوشي: `arabic` / `evaluator`
- الأستاذة عائشة الغفلي: `aisha` / `evaluator`
- طلال معتوق على سعيد النعيمي: `vp` / `vice_principal`
- مسؤول منصة أَثَر المستقل: `ather` / `platform_admin`

## احتياطات إلزامية
1. لا تشغّل `initializeDatabase` أو أي دالة تهيئة.
2. لا تحذف صفوف Users أو RegisteredVisitors أو CentralUsers.
3. لا تنسخ passwordHash أو salt من CentralUsers إلى Users.
4. الحسابات الجديدة تنشأ بحالة `inactive`، ويجب تعيين كلمة مرور مستقلة وآمنة قبل تفعيلها.
5. لا تشغّل دالة التطبيق قبل قراءة المعاينة ومراجعتها واعتمادها صراحةً.
6. احتفظ بنسخة احتياطية من ملف Google Sheets قبل أي تطبيق فعلي.

## خطوات المعاينة فقط
1. افتح مشروع Apps Script المرتبط بمنصة أَثَر.
2. أضف ملف Script جديداً باسم `AccountIdentityMigration`.
3. انسخ محتوى `gas/AccountIdentityMigration.gs` من هذا الفرع إلى الملف الجديد ثم احفظ.
4. من قائمة الدوال اختر `previewAccountIdentityMigration_` وشغّلها.
5. وافق على أذونات Google المطلوبة لقراءة جدول البيانات إذا ظهرت.
6. راجع سجل التنفيذ (Execution log) ونتيجة الدالة. هذه الدالة للقراءة فقط.
7. إذا ظهرت أي `blockers`، أوقف الإجراء ولا تشغّل التطبيق. يجب معالجة السبب ومراجعة المعاينة مجدداً.

## التطبيق
التطبيق ليس جزءاً من هذه الخطوات ولا ينبغي تشغيله تلقائياً. لا تستخدم `applyAccountIdentityMigration_` إلا بعد مراجعة المعاينة والنسخة الاحتياطية وموافقة مالك البيانات صراحةً. يتطلب وسيط التأكيد النصي الموجود داخل الملف.

## ما لم يحدث
- لم تُنفّذ المعاينة أو أي كتابة على Google Sheets من خلال هذا التغيير.
- لم يُنشر مشروع Apps Script أو يُحدّث Web App.
- لم يُدمج طلب GitHub رقم 25.
